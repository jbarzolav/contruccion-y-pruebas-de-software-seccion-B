# HU62.3 — Acceso a pedidos (Spring)

Verificación con MockMvc y H2: `mvn -Dtest=PedidoDetalleControllerTest,MetricasVentasControllerTest test`. Las 19 pruebas de ambos controladores pasaron. En `GET /api/pedidos/{id}` se rechazan las consultas sin sesión (401) y las de una compra de otro cliente (403); en `GET /api/vendedores/me/metricas/ventas` una sesión sin rol vendedor recibe 403. La identidad la aporta el Bearer, no el ID de la URL.
